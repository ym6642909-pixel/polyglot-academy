# Polyglot Academy Pro

منصة ويب عربية لتعلم الإسبانية والروسية والفرنسية والألمانية.

## التشغيل
- فك ضغط الملف.
- افتح `index.html` بمتصفح حديث.
- لا تحتاج النسخة الأساسية إلى Node.js أو تثبيت حزم.

## الموجود في النسخة Pro
- لوحة تعلم وإحصائيات ونقاط.
- أربع لغات مع ستة مستويات ظاهرة (A1–C2).
- وحدات تعليمية نموذجية قابلة للتوسعة.
- نطق عبر Speech Synthesis حسب دعم المتصفح والأصوات المثبتة.
- اختبارات اختيار من متعدد مع نتيجة ونقاط.
- بطاقات مفردات، قائمة كلمات أتقنتها، ومراجعة.
- مساعد تعليمي تجريبي محلي (ليس نموذج AI حقيقياً).
- حفظ التقدم محلياً عبر Local Storage.
- تصميم متجاوب وواجهة عربية RTL.

## هيكل الملفات
- `index.html`: واجهة التطبيق.
- `styles.css`: التصميم.
- `app.js`: المناهج والاختبارات والتفاعلات والحفظ المحلي.
- `manifest.json`: بيانات تثبيت PWA.

## حدود النسخة الحالية بشفافية
1. المناهج الحالية محتوى تأسيسي توضيحي، وليست مكتبة كاملة بمئات الدروس لكل مستوى.
2. ظهور المستويات A1–C2 لا يعني أن كل مستوى مكتمل المحتوى بعد؛ الدروس النموذجية نفسها تستخدم كبداية قابلة للتوسعة.
3. المدرس الذكي الحالي وضع تجريبي محلي بقواعد رد بسيطة، وليس اتصالاً فعلياً بنموذج ذكاء اصطناعي.
4. لا يوجد تسجيل دخول أو قاعدة بيانات أو مزامنة بين الأجهزة.
5. البيانات محفوظة في المتصفح الحالي وقد تضيع عند مسح بيانات الموقع.

## تحويل المدرس التجريبي إلى AI حقيقي
أنشئ Backend (مثلاً Node.js + Express) يستقبل الرسائل من الواجهة، ويتصل بمزود النموذج من جهة الخادم. خزّن مفتاح API في متغير بيئة مثل `AI_API_KEY` ولا تضعه في `app.js` أو أي ملف يصل للمتصفح. أضف حدود استخدام ومصادقة وحماية من إساءة الاستخدام قبل النشر العام.

## النشر
يمكن رفع الملفات إلى GitHub Pages أو أي استضافة ملفات ثابتة. للحصول على مزامنة وحسابات وAI حقيقي، ستحتاج Backend وقاعدة بيانات واستضافة للخادم.
